E-STIM REMOTE WEB

かんたんガイド

離れた相手からE-STIMを操作できるWebアプリです。専用アプリのインストールは必要ありません。

受信側E-STIM本体を接続する端末
送信側操作するスマホ・PC

受信側

  1. E-STIM REMOTE WEBを開き、「受信側」を選ぶ
  2. 「E-STIMデバイスを検索」から本体を接続
  3. E-STIM READYになったら「ROOMを開始」
  4. 表示されたQRコードまたはJOIN URLを相手へ送る
  5. 接続申請が来たら、相手を確認して「操作を許可」
  6. A / B LIMITを安全な強さに設定
  7. 実機へ出力するときだけ「REAL REMOTE READY」

送信側

  1. 受信側から届いたQRコードまたはJOIN URLを開く
  2. 表示名を確認して「接続を申請する」
  3. 受信側の許可を待つ
  4. 許可されたらPRESETやPOWERを操作する

止めたいとき

ALL ZERO出力を0にする
ZERO / LOCK遠隔実機出力を停止
E-STOP緊急停止

通信が切れたり、画面が閉じられたりした場合も、安全のため実機出力は停止します。

iPhone / iPadについて

iPhone / iPadは、通常は送信側・閲覧側として使用できます。

E-STIM本体をBluetooth接続する受信側は、Windows PC＋Chrome / Edge推奨です。

ただしiPhone / iPadでも、Bluefy / WebBLEなどのWeb Bluetooth対応ブラウザを使用すると、受信側として動作する可能性があります。iOSでの実機接続は、現時点では実験的対応・動作保証外です。

送信中は、画面ロック・ブラウザ終了・他アプリへの切り替えなどで安全停止する場合があります。

基本の流れ

受信側：E-STIM接続 → ROOM開始 → QR / URLを送る
↓
送信側：QR / URLを開く → 接続申請
↓
受信側：操作を許可 → LIMIT確認 → REAL REMOTE READY
↓
送信側：操作開始
