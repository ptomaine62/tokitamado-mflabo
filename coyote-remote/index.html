受信側のあそびかた
  1. E-STIMデバイスを接続します。
  2. ROOMを開始し、QRコードまたはURLを相手へ送ります。
  3. 届いた接続申請を確認し、操作を許可します。
  4. 実機出力する場合は REAL REMOTE READY を押します。
  5. LIMIT / ALL ZERO / E-STOP は受信側がいつでも優先できます。

    参加者
    LIMITとE-STOPは受信側が常に最終権限を持ちます。
    まずここからROOM CODEを入力して「接続を申請する」。受信側の許可後に操作できます。
    送信側のあそびかた
    1. QRコードを読むか、ROOM CODEを入力します。
    2. 表示名を確認して「接続を申請する」を押します。
    3. 受信側の許可を待ちます。
    4. 許可後、PRESET / POWER / PLAY で刺激を操作します。
    5. 他の送信側へ操作権が移ると待機状態になります。
    —
    受信側の許可後に操作できます。
    閲覧側のあそびかた
    1. ROOM CODEを入力して「見る」を押します。
    2. 刺激の種類・Power・グラフをリアルタイムで確認できます。
    3. イベントログでは誰が誰に何を送っているかを追えます。
    4. 閲覧側から刺激操作はできません。
    —
    閲覧モードは書き込み命令を送信しません。
